# Support

## Documentation

Start with the `docs/` directory and the README.

## Getting help

- Open an issue for bugs and feature requests (see
  [CONTRIBUTING.md](CONTRIBUTING.md)).
- Report security vulnerabilities privately per
  [SECURITY.md](SECURITY.md).

## Operating responsibility

JABARI is an **authorized-use** tool. Ensure you have explicit permission
before assessing any device, and review the
[Security Model](docs/Security-Model.md) before deploying it in an
organization.
